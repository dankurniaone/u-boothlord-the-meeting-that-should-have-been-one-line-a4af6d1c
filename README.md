A make.fun entry for [The Meeting That Should Have Been One Line](https://make.fun/competitions/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c): the single sentence that could have replaced an entire pointless meeting.

> We agreed in the meeting to stop having meetings, then booked a recurring one to check we had stopped.

The meeting's own decision defeats itself. `main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` and verifies the gate: 1–200 UTF-8 characters, exactly one sentence, byte-identical round-trip.

Run it:

```sh
python3 main.py          # writes /output/entry.txt
python3 main.py --check  # dry run, prints the line and its length
python3 main.py --self-test  # full gate check without touching /output
```
